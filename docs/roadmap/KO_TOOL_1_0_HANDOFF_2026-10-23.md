## Утверждённая последовательность

1. My EP — полная функциональность + CI + подтверждённые HIL; официальный EP Sample Tool основной референс. EP-1320 только проверенные возможности.
2. SpeedUpperCut — минималистичная пакетная конвертация ×2/−12, HI/MID/LO, режимы каналов/воспроизведения, ZIP/WAV, drag в My EP, исключить повторный REPITCH; HIL.
3. Visuals — 7 визуализаторов, реальный LUFS, WAV-рекордер 16/24 bit, 3 темы, адаптивный FPS, индивидуальная визуальная приёмка каждого модуля и строгие стресс-тесты.
4. Sequencer — **самостоятельное приложение**, физический EP source of truth, реальный Step/Piano Roll/live, каждая команда требует аппаратных доказательств.
5. FX-MIC Studio / EP-2350 — автономный редактор/Emulation и **обязательный проверенный USB Live**; отдельное приложение.
6. EP-136 Sidekick — **аудиоинтерфейс и диагностика только через Visuals**, без отдельной иконки, MIDI-микшер/пресеты вне 1.0.

**Платформа:** только обязательная приёмка **macOS 12 Monterey+, Google Chrome, MacBook Pro 13″ 2017 Core i5/8 GB**; iPhone после релиза; Visuals только десктоп. Остальные приложения — стабильность без числовых FPS/CPU/RAM требований.

**Разработка:** одно приложение за раз, одна инженерная задача за раз, по критическому пути. Блокировки не обходить. Аудит GitHub/Linear, оригинальных источников, точных функций и тестов прежде любой правки кода.

**Финальный релиз:** шесть этапов приняты, применимые тесты и CI зелёные, HIL по установленным критериям, критических ошибок нет; extra RC-цикл отдельно не обязателен. Merge/deploy после завершённого CI и отдельного разрешения.

**README:** только пользовательская документация. Убрать инструкции агентам/процедуры/планы; обновлять после каждого подтверждённого релиза. Агенты читают AGENTS.md и профильные документы.

**Linear:** один Release 1.0 проект, шесть этапов, инженерный паспорт задач, реальные источники + тесты + HIL + риски + сложность и неопределённость; существующие задачи не дублировать. Пользователь выбрал **двухшаговое согласование**: сначала утверждение инженерного плана, потом отдельное разрешение на массовую реорганизацию Linear. Отдельно **23.10.2026 дал разрешение только зафиксировать решения в GitHub/Linear и сократить README**, но **не разрешал реализацию функций**.
