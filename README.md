# K.O. Tool

**K.O. Tool** — независимый браузерный набор инструментов для подготовки аудиосэмплов, работы с совместимыми устройствами Teenage Engineering EP и визуализации звука.

**[Открыть K.O. Tool](https://zatumanen.github.io/Ko-tool/)** · **[Сообщить об ошибке](https://github.com/Zatumanen/Ko-tool/issues)**

## Возможности

### SpeedUpperCut

Подготовка аудиофайлов и папок для сэмплера. Доступны ускорение ×2 с метаданными компенсации высоты звука, качество **HI / MID / LO**, выбор каналов **Mono / Stereo / Original** и режима воспроизведения **One Shot / Loop / Original**. В текущем интерфейсе доступны предпросмотр и инструменты работы с волной. Результат можно сохранить в **WAV** или **ZIP**.

### My EP

Работа с подключённым Teenage Engineering EP через USB: библиотека сэмплов, просмотр доступных метаданных, размещение и передача сэмплов, просмотр сохранённых проектов и параметров пэдов. В разделе Projects также присутствует ограниченный редактор шагов проекта.

**Важно:** поддержка конкретной операции зависит от модели, прошивки и состояния устройства. Распознавание модели не означает, что запись и редактирование разрешены.

### Visuals

Семь визуальных модулей для **выбранного аудиовхода**: Waveform, Spectrum, Spectrogram, Oscilloscope, Loudness, Stereo Meter и Output Meters.

Visuals получает звук только с явно выбранного доступного браузеру аудиовхода (например, микрофона или аудиоинтерфейса). USB MIDI **не передаёт аудио**. Показатель Loudness в текущей версии основан на **RMS dBFS**, а не LUFS.

## Как начать

### Подготовить аудио

1. Откройте K.O. Tool в браузере и запустите **SpeedUpperCut**.
2. Выберите аудиофайл или папку либо перетащите их в приложение.
3. Укажите качество, каналы и режим воспроизведения.
4. Прослушайте результат и сохраните WAV или ZIP.

**Примечание:** метаданные sound.pitch = −12 предназначены для компенсации скорости при воспроизведении на совместимом EP. Фактический результат зависит от настроек сэмплера.

### Подключить устройство EP

1. Откройте K.O. Tool в настольном **Google Chrome** по HTTPS.
2. Подключите EP к компьютеру через USB и запустите **My EP**.
3. Разрешите доступ к **Web MIDI / SysEx**, затем дождитесь распознавания устройства.
4. Прежде чем изменять данные или восстанавливать проект, сделайте резервную копию и внимательно проверьте показанные подтверждения.

### Включить Visuals

1. Откройте **Visuals** на компьютере.
2. Разрешите браузеру доступ к аудиовходу, если потребуется.
3. Выберите нужный источник и нажмите **START**.
4. Для остановки захвата нажмите **STOP**.

## Совместимость

Для работы **My EP** нужен настольный браузер с Web MIDI/SysEx, разрешённым доступом к USB MIDI и поддерживаемой моделью/прошивкой. Рекомендуется **Google Chrome на macOS**. Возможности других браузеров зависят от поддержки необходимых API.

В текущей версии распознаются:

- **EP-133 K.O. II**
- **EP-1320 Medieval**
- **EP-40 Riddim**

Доступность чтения, загрузки или изменения данных **различается** между моделями и версиями прошивки. Неподтверждённые операции блокируются ради сохранности данных.

SpeedUpperCut работает без MIDI-подключения при наличии поддержки браузером Web Audio и используемых аудиоформатов. Отдельные форматы могут не декодироваться в конкретном браузере.

## Важные особенности

- **Свободная память и слоты:** перед загрузкой проверьте назначение файлов и целевые слоты. Занятые слоты не следует перезаписывать без осознанного подтверждения.
- **Имена сэмплов:** числовой префикс в начале имени, например «056 Kick.wav», может интерпретироваться My EP как номер слота. SpeedUpperCut и My EP обрабатывают такие имена по-разному.
- **Проекты:** доступный просмотр сохранённого состояния не означает непрерывной синхронизации в реальном времени. При отключении USB нужно заново подтвердить актуальность данных.
- **Безопасность:** не отключайте EP в процессе записи или проверки. Если произошёл обрыв соединения либо операция сообщает об ошибке, сначала проверьте состояние устройства и не повторяйте запись наугад.

## Если возникла проблема

| Проблема | Что проверить |
| --- | --- |
| My EP не находит устройство | USB, Google Chrome, HTTPS, разрешение Web MIDI/SysEx, модель и прошивку. Закройте другие приложения, управляющие тем же EP. |
| Не удаётся загрузить сэмпл | Свободное место, целевой слот, поддерживаемые метаданные и состояние устройства. |
| Проект показывает старые данные | Обновите сохранённые данные через **Refresh**; не путайте их с несохранённым состоянием устройства. |
| Файл не открывается в SpeedUpperCut | Попробуйте PCM WAV и проверьте, может ли браузер декодировать исходный формат. |
| Visuals не показывает сигнал | Выбранный аудиовход, разрешение браузера, START и физическую маршрутизацию звука. |

При сообщении об ошибке полезно указать действия, версию macOS/Chrome, модель EP и версию прошивки. **Не публикуйте** серийные номера, приватные резервные копии, содержимое проектов или секретные данные устройства.

## Правовой статус

K.O. Tool — независимый проект, **не официальный продукт Teenage Engineering**. Открытый доступ к репозиторию не означает, что его содержимое свободно для повторного использования: условия использования отдельных материалов и зависимостей могут различаться.
