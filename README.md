# K.O. Tool

**K.O. Tool** — независимая браузерная творческая среда и компаньон
для сэмплеров серии EP от Teenage Engineering. Виртуальный рабочий стол
объединяет отдельные инструменты, к которым можно переходить через иконки:
**SpeedUpperCut** готовит аудиофайлы с экономией памяти, а **My EP** помогает
управлять подключённым физическим устройством, включая будущий просмотр
секвенций прямо в **My EP**. В перспективе на рабочем столе появится
**Visuals** — отдельное приложение для аудиовизуализации и съёмки лайвов;
другие инструменты, включая обмен контентом, пока обсуждаются.

**[Открыть K.O. Tool](https://zatumanen.github.io/Ko-tool/)** ·
[Сообщить о проблеме](https://github.com/Zatumanen/Ko-tool/issues)

Цель проекта — **экономить память EP и избавлять музыканта от неудобных
операций с файлами**, одновременно делать работу с устройством увлекательной.
Приложение должно дополнять железный сэмплер, а не подменять его музыкальный
процесс.

### Экономия памяти: философия SpeedUpperCut

Ускорение звуковых данных в **2 раза** сокращает их длительность и, при
сопоставимых параметрах PCM, примерно вдвое уменьшает занимаемое место.
Компенсационное значение `sound.pitch=-12` предназначено для воспроизведения
на EP с восстановлением исходной высоты и длительности в выбранном рабочем
сценарии. Результат зависит от последующей обработки и настроек пэда;
качество и правильность компенсации проверяются отдельно на реальном устройстве.

**Согласованное будущее поведение — переключатель `REPITCH` в My EP:**
переключатель **включён по умолчанию**, его можно отключить вручную.
При включённом REPITCH перед каждой прямой загрузкой My EP анализирует
WAV-метаданные Teenage Engineering (`LIST/INFO/TNGE`, поле `sound.pitch`):

| Входящий файл | Что произойдёт при загрузке |
| --- | --- |
| WAV содержит `sound.pitch = -12` | Пропускаем повторное ×2 и сохраняем компенсацию `-12`. Если устройство требует совместимый PCM-формат, приводим формат **без повторного ускорения**. |
| Значения `sound.pitch = -12` нет, в том числе MP3/другое аудио без такого WAV-чанка | Обрабатываем звук ×2, создаём нужный формат и устанавливаем `sound.pitch = -12` перед передачей. |
| `REPITCH` отключён | Используем существующую прямую загрузку My EP без автоматического ×2. |

**Важно:** поле `sound.pitch = -12` используется как **договорный маркер**
подготовленного файла, а не как гарантия того, что звук реально ускорен ×2.
Повреждённые метаданные требуют явной ошибки, а не молчаливого решения, что
метки нет. REPITCH относится к **новым импортируемым файлам**: копирование,
перемещение и восстановление уже записанных данных не должны неявно менять
звук. Исходный локальный файл не переписывается.

**Статус:** это утверждённая владельцем спецификация поведения, **но она пока
не реализована в My EP**. В действующем `main` конвертер выполняет ×2/`-12`,
а прямой импорт My EP имеет отдельный путь подготовки. Перед реализацией
нужны отдельные тесты и проверка на физическом EP.


### Быстрый старт

**Подготовить сэмпл**

1. Откройте [приложение](https://zatumanen.github.io/Ko-tool/).
2. Нажмите **Select Files** или **Select Folder**, либо перетащите аудио в окно.
3. Выберите **HI / MID / LO**, режим каналов и режим воспроизведения.
4. Прослушайте результат и скачайте подготовленный WAV или ZIP с результатами
   обработки папки.

**Работать с устройством EP**

1. Используйте **настольный Chrome или Edge** и страницу по HTTPS/localhost.
2. Подключите совместимый EP к компьютеру через USB и откройте **My EP**.
3. Разрешите браузеру доступ **Web MIDI и SysEx**, затем дождитесь загрузки
   библиотеки сэмплов. Возможность конкретной операции зависит от прошивки.
4. Перед удалением сэмплов, изменением проектов или восстановлением создайте
   резервную копию. Не отключайте устройство во время записи/проверки.

### Возможности

| Конвертер x2 | My EP |
| --- | --- |
| Отдельные аудиофайлы и целые папки | Чтение библиотеки сэмплов и метаданных |
| Скорость ×2 и компенсационная metadata `sound.pitch=-12` | Поддерживаемые операции загрузки, выгрузки и воспроизведения |
| HI: 46 875 Гц; MID: 32 000 Гц; LO: 26 250 Гц | Переименование, копирование, перемещение и удаление с проверками |
| Mono / Stereo / Original | Явный выбор номера слота или следующего свободного при загрузке пронумерованных файлов |
| One Shot / Loop / Original, необязательная обрезка тишины | Просмотр сохранённых проектов, доступные функции резервного копирования и восстановления |
| Работа с волной, нарезка, предпрослушивание, WAV/ZIP | Ручной Refresh проектов или опциональный `AUTO: ON` |

Конвертер принимает аудиофайлы с расширениями WAV, MP3, AAC, OGG, FLAC,
M4A и некоторыми другими, **если аудиодекодер конкретного браузера
поддерживает их содержимое**. Необрабатываемые и служебные файлы macOS
в пакетах пропускаются или обозначаются как ошибки; успешно обработанные
файлы сохраняются в результате.

**Конвертер и My EP по-разному работают с именами:** при обычном скачивании
`056 Classic Kick.wav` становится `056 Classic Kick_x2.wav`. При экспорте
папки суффикс `_x2` добавляется к папке, но не к каждому WAV внутри ZIP.
При загрузке в EP префикс слота может быть снят с имени на самом устройстве:
`1_micro kick.wav` предлагает слот `001`, а имя становится `micro kick`
(с учётом правил нормализации EP). Допустимы префиксы от `1` до `999`
длиной 1–3 цифры с последующим пробелом, табуляцией или `_`.
Занятые слоты не перезаписываются без предупреждения.

**Важно:** описанный выше переключатель REPITCH — будущая функция, а не
элемент сегодняшнего интерфейса My EP. Сейчас режим ×2 конвертера — не то же
самое, что прямая загрузка сэмпла. Права на запись, поддержка проектов и форматы данных
зависят от модели, точной версии прошивки и проверенной совместимости.
Просмотр проекта сам по себе не означает, что его можно безопасно изменить.

### Направления развития

Мы планируем не заменить EP программной DAW, а добавить то, что особенно
удобно делать на большом экране: видеть структуру паттернов, сцен и сонга;
быстро собирать, слушать и переносить комплекты сэмплов; создавать резервные
копии и безопасно возвращаться к предыдущему состоянию; получать понятные
контекстные подсказки.

**Секвенсор: утверждён двухэтапный сценарий (вариант C).** Сначала —
качественный **просмотр сохранённых секвенций**: ноты/шаги, пэды,
паттерны групп A–D, сцены и связи между ними. Затем — отдельный **LIVE-режим**,
в котором отображаются происходящие на подключённом EP события и позиция
воспроизведения, *только в пределах реально подтверждённых возможностей
устройства и MIDI-протокола*. Сейчас My EP уже умеет читать проект и показывать
часть его структуры; в `main` также есть 16-шаговый редактор `SEQUENCER`,
доступный только при прохождении дополнительных проверок. Это не означает,
что в продукте уже есть полноценный read-only piano roll или надёжная
синхронизация с движущимся playhead.

**Размещение — внутри My EP:** открыть **My EP → Projects → выбрать проект → Sequencer**. Секвенсор не получает отдельную иконку на виртуальном рабочем столе. Сохраняются общий контекст выбранного проекта, безопасные ограничения на запись и возможность вернуться к Projects.

**Доступ к проектам — только с физически подключённым EP (утверждённый вариант B).** Просмотр сохранённых проектов, Step Sequencer, Piano Roll и будущая LIVE-синхронизация работают в контексте активного подключения My EP. Режим открытия локального архива проекта без EP **не планируется**. При отключении устройства не предоставлять автономный просмотр или редактирование проекта; показывать понятный статус подключения без риска записи. Это требование к продукту, а не утверждение о полной готовности будущего секвенсора. **SpeedUpperCut остаётся доступен без EP**.

**Выбранный интерфейс — два переключаемых вида одного проекта:**
**Step Sequencer** (пэды/дорожки по вертикали, 16 шагов по горизонтали,
страницы и длительности) и **Piano Roll** (высота и длительность нот по
временной оси). Оба вида должны читать единый набор событий, одинаково
показывать неопределённые/неподдерживаемые записи и быть доступны в
безопасном read-only режиме. Это утверждённое направление развития,
**не функция, уже доступная в main**. Подробности — в docs/SEQUENCER.md.

Периодическое чтение сохранённого проекта (`AUTO: ON`, раз в 20 секунд)
**не является** живым отображением несохранённых шагов или транспортной
синхронизацией. Во время игры на EP по умолчанию оно выключено
(`AUTO: OFF`); будущий LIVE-режим не должен просто ускорять FILE-опрос.
Подробная спецификация, текущие ограничения и критерии приёмки —
[docs/SEQUENCER.md](docs/SEQUENCER.md).

**Решение владельца — отдельное приложение Visuals (вариант A).** Оно получит
**собственную иконку на виртуальном рабочем столе K.O. Tool**, а не вкладку
в My EP. Предполагаются waveform, spectrum, oscilloscope и другие виды
динамической графики для выступлений, съёмки лайвов и оформления видео.
**Выбор владельца — универсальный аудиовход (вариант C):** пользователь сам
выбирает **EP по USB Audio**, если устройство действительно доступно как
аудиовход компьютера и браузера, **или любой другой поддерживаемый аудиовход**
(аудиоинтерфейс/line-in, микрофон и т. п.). **Подключение EP для Visuals не
обязательно**, если выбран другой источник. Выбор входа требует явного
разрешения браузера; при отключении источника нельзя незаметно переключаться
на встроенный микрофон. Сам по себе USB MIDI/SysEx **не передаёт аудио**.

**Утверждённый интерфейс Visuals:** основное представление — **длинная
докированная полоска вдоль нижнего края окна/экрана K.O. Tool**, как на
предоставленном владельцем референсе в духе MiniMeters. Для первой версии
выбран **максимальный набор из семи модулей**: Waveform, Spectrum,
Loudness, Stereo Meter, Output Meters, Oscilloscope и Spectrogram.
**Стартовая компоновка — сбалансированная (вариант C):** крупные **Waveform**
и **Spectrum**, средний **Spectrogram**, компактные **Loudness**,
**Stereo Meter**, **Output Meters** и **Oscilloscope**. Это распределение
пространства по важности, а не утверждённый порядок слева направо.
Первоначально доступны все семь модулей; на узких экранах действует
ранее согласованное уменьшение ширины и горизонтальная прокрутка.

**Настройка полоски — утверждён вариант C:** модули можно **перетаскивать,
менять их ширину, скрывать и возвращать**. Предусмотрены готовые компоновки
для **битмейкинга, сведения и съёмки лайвов**, а также **сохранение и
повторная загрузка собственных пресетов**. Все семь модулей остаются
доступными, но необязательно показываются одновременно. **Адаптация к ширине экрана — утверждён вариант C:** при сужении окна
видимые модули уменьшаются до комфортного минимального размера. Если места
не хватает даже тогда, нижняя полоска **прокручивается горизонтально**.
Приложение не скрывает и не переставляет модули без решения пользователя.
Временное сжатие не изменяет сохранённые пользовательские пресеты.
Точный порядок модулей слева направо, численные ограничения размеров,
содержимое остальных пресетов и сохранение между браузерами ещё нужно спроектировать.
**Поведение полоски — утверждён вариант C:** по умолчанию она **всегда
видима**, но пользователь может включить **автоскрытие** с появлением при
наведении к нижнему краю K.O. Tool или **свернуть её вручную** с возможностью
вернуть обратно. Скрытие всей полоски не должно сбрасывать расположение и
состав модулей. Детали управления и работы с аудио при скрытии ещё определим.

**Темы Visuals — обновлённое решение владельца:** четыре темы — **Retro / WIN**,
**EP-133**, **EP-40** и **Minimal**. Retro опирается на цвета нашего рабочего
стола в стиле Windows 95 (бирюзовый `#008080`, серый `#c0c0c0`,
тёмно-синий `#000080` из `css/base.css`). Темы EP-133 и EP-40
будут оформлены по мотивам внешнего вида соответствующих физических устройств.

**После успешного распознавания устройства в My EP** Visuals автоматически
выбирает тему **EP-133** для `TE032AS001` или **EP-40** для
`TE032AS006`. Без распознанного устройства базовая тема — **Retro / WIN**;
это **не мешает Visuals работать с другим выбранным аудиовходом**.
**Приоритет тем — выбран вариант B:** **Auto Theme включён по умолчанию**.
После ручного выбора любой из четырёх тем автоматическая смена **отключается**,
и выбранное оформление не изменится при последующих подключениях или смене EP,
пока пользователь явно не включит **Auto Theme** снова. При повторном включении
тема подбирается по подтверждённой модели EP-133/EP-40; без распознанного
устройства используется базовая Retro / WIN.

Проект также распознаёт EP-1320, но его оформление ещё предстоит согласовать.
Поведение автоматической темы при отключении уже распознанного устройства
и сохранение выбора Auto Theme после перезагрузки страницы пока не решены.

Все четыре темы доступны для ручного выбора, остаётся **индивидуальная
настройка цветов модулей**. Смена темы не должна сбрасывать источник звука,
компоновку, пресеты и видимость модулей. Точные оттенки EP-133/EP-40/Minimal
ещё требуют визуальной проработки.

Обычный браузер не может поверх других приложений ОС закрепить настоящую
системную always-on-top полоску — здесь речь о нижней панели внутри K.O. Tool.

Visuals пока **не реализовано**. Поддержку конкретного EP/прошивки, захват
USB Audio и задержку нужно проверить на реальном устройстве.
Спецификация — [docs/VISUALS.md](docs/VISUALS.md).

Также исследуем общую библиотеку сэмплов, комплектов и проектов. Перед её
разработкой потребуется определить права на контент, лицензионные условия,
модерацию, безопасность файлов, приватность и финансирование инфраструктуры.
Добровольные донаты рассматриваются как одна из моделей поддержки проекта;
никакого решения о подписке или платном доступе пока нет.

Публичный план и подтверждённые задачи ведутся в Linear; направления выше —
продуктовое видение, **не перечень уже доступных возможностей**.

### Совместимость и ограничения

| Возможность | Условия |
| --- | --- |
| Конвертер | Нужны Web Audio, выбор файлов и доступный ресэмплер WebAssembly. Chromium используется для автоматических E2E; другие браузеры — по фактическим возможностям. |
| My EP по USB | Настольный Chrome/Edge, HTTPS или `localhost`, Web MIDI с SysEx, разрешение браузера, совместимый EP. |
| iPhone, iPad и другие мобильные устройства | Конвертация — по возможностям браузера и памяти; **управление EP по MIDI в текущей версии не поддерживается**. |
| Распознаваемые EP | EP-133 K.O. II, EP-1320 Medieval и EP-40 Riddim. Распознавание устройства не гарантирует разрешения на запись. |

Большие аудиофайлы могут потребовать значительного объёма оперативной
памяти. Работа с устройством зависит также от USB-соединения, разрешений и
конкретной прошивки. Детали приведены в
[политике браузеров](docs/testing/browser-platform-support.md) и
[матрице EP](docs/testing/ep-device-compatibility-matrix.md).

### Если что-то не работает

| Симптом | Что проверить сначала |
| --- | --- |
| My EP не открывается на телефоне | Это ограничение текущего продукта; используйте настольный Chrome/Edge. |
| Браузер не видит EP | Проверьте USB, HTTPS/localhost, доступ MIDI/**SysEx**, модель и прошивку. Не запускайте параллельно несколько управляющих EP-приложений. |
| Аудиофайл не декодируется | Попробуйте стандартный PCM WAV; ошибки кодеков зависят от браузера и содержимого файла. |
| Содержимое Projects не обновилось | Нажмите **Refresh**; периодическое чтение нужно включить вручную кнопкой **AUTO: ON**. По умолчанию **AUTO: OFF**. |
| Действие с сэмплом заблокировано | Проверьте занятый слот, разрешения устройства, состояние сессии и ссылки на сэмпл из проектов. Не обходите предупреждения. |

Для воспроизводимой ошибки пригодятся: действие, версия браузера и ОС,
модель EP, версия прошивки, точный текст ошибки и шаги воспроизведения.
**Не публикуйте серийные номера устройства, приватные резервные копии,
сырой SysEx-трафик с личными данными или секреты.**

## Для разработчиков и AI-агентов

### Локальный запуск

Репозиторий содержит **статическое приложение на HTML, CSS и JavaScript**.
Отдельного серверного API и базы данных для работы опубликованного продукта
нет. **Node.js 22** используется в текущих GitHub Actions для сборки и
тестирования (это подтверждённая версия CI, а не обещание совместимости
со всеми другими версиями Node).

```bash
git clone https://github.com/Zatumanen/Ko-tool.git
cd Ko-tool
npm install --no-audit --no-fund
node tests/e2e/server.mjs
```

Откройте **http://127.0.0.1:4173/**. Для ручного просмотра сервер нужно
оставить запущенным. В текущей реализации тестового сервера порт `4173`
фиксированный. Перед `npm run test:e2e` остановите ручной сервер:
Playwright запускает собственный экземпляр на том же порту и не
переиспользует уже запущенный.

### Тестирование и безопасность

```bash
npm test
npm run build:pages
npx playwright install chromium
npm run test:e2e
```

`npm test` использует встроенный Node test runner, браузерные E2E используют
Playwright с Chromium и симулированным MIDI-устройством. Сборка
`build:pages` создаёт `dist/` и `build-version.json`; `dist/` не нужно
редактировать вручную. Полная последовательность и матрица аппаратной
проверки — в [docs/TESTING.md](docs/TESTING.md).

**Автоматические тесты с fake EP не доказывают совместимость с физическим EP.**
Перед закрытием критических задач нужны отдельные испытания с конкретной
моделью, прошивкой, резервной копией, проверкой чтения после записи и
документированным результатом. Не проводите опасные операции на ценных
проектах.
