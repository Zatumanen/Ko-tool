# K.O. Tool

**K.O. Tool** — независимая браузерная творческая среда и компаньон для сэмплеров Teenage Engineering EP. Внутри виртуального рабочего стола объединены подготовка аудио, работа с подключённым EP и визуализация звука. Цель — экономить память устройства и облегчать музыкальную работу, а не заменять аппаратный сэмплер программной DAW.

**[Открыть K.O. Tool](https://zatumanen.github.io/Ko-tool/)** · [Сообщить об ошибке](https://github.com/Zatumanen/Ko-tool/issues) · [План Release 1.0](https://linear.app/clouded/project/ko-tool-release-10-2f713ebc0fca)

## Приложения и текущее состояние

| Приложение | Возможности и статус |
| --- | --- |
| **SpeedUpperCut** | Подготовка аудио ×2 с компенсацией `sound.pitch=-12`, выбор качества, каналов и режима воспроизведения, работа с волной, файлами и папками, экспорт WAV/ZIP. Доступно. |
| **My EP** | Подключение физического EP, библиотека сэмплов, перенос, просмотр метаданных и проектов. Запись и изменение данных ограничены подтверждёнными возможностями модели/прошивки и безопасным состоянием устройства. |
| **My EP → Projects → Sequencer** | Уже есть инспектор сохранённых проектов и ограниченный 16-шаговый редактор. Полноценные **read-only Step Sequencer и Piano Roll**, а затем аппаратно подтверждённый **Live**, остаются целями разработки. Отдельной иконки секвенсора нет. |
| **Visuals** | Отдельная иконка, нижняя браузерная полоска с семью модулями: Waveform, Spectrum, Loudness, Stereo Meter, Output Meters, Oscilloscope и Spectrogram. Выбор аудиовхода, компоновки и темы. Реализовано в браузере; USB Audio конкретных EP требует отдельной аппаратной проверки. |

Экспериментальная оболочка Speeduppercut OS из [Draft PR #110](https://github.com/Zatumanen/Ko-tool/pull/110) приостановлена и не является текущим интерфейсом продукта.

## Быстрый старт

### Подготовить сэмплы

1. Откройте [K.O. Tool](https://zatumanen.github.io/Ko-tool/), запустите **SpeedUpperCut** и выберите файлы/папку либо перетащите аудио.
2. Выберите **HI / MID / LO**, каналы (**Mono / Stereo / Original**) и режим воспроизведения (**One Shot / Loop / Original**).
3. Проверьте звук и скачайте WAV или ZIP.

Ускорение ×2 сокращает длительность аудиоданных и примерно вдвое уменьшает объём при сопоставимом PCM. Метаданные `sound.pitch=-12` предназначены для компенсации при воспроизведении на EP; результат зависит от настроек и требует проверки на устройстве. Подробности: [аудиоконтракт](docs/testing/audio-x2-pipeline.md).

### Подключить EP

1. Откройте сайт в настольном **Chrome или Edge** по HTTPS (или на `localhost`), подключите EP через USB и запустите **My EP**.
2. Разрешите **Web MIDI и SysEx**, дождитесь подтверждения модели и загрузки данных.
3. Перед изменением проектов, удалением или восстановлением сделайте резервную копию. Не прерывайте операцию во время записи и проверки.

### Включить Visuals

Откройте **Visuals**, выберите доступный браузеру аудиовход и нажмите **START**. Если список устройств требует разрешения, воспользуйтесь **ACCESS**. USB MIDI не передаёт звук; EP USB Audio будет доступен только при поддержке устройства, ОС и браузера. **STOP** прекращает захват. Семь модулей и предустановленные компоновки настраиваются внутри приложения.

## Совместимость и важные ограничения

| Функция | Условия |
| --- | --- |
| **Конвертер** | Web Audio и встроенный WebAssembly. WAV, MP3, AAC, OGG, FLAC, M4A и другие форматы декодируются только при поддержке браузером конкретного содержимого. |
| **My EP по USB** | Настольный Chrome/Edge, безопасный контекст, Web MIDI/SysEx, разрешение пользователя, совместимая модель и точная поддерживаемая прошивка. |
| **Модели** | Распознаются EP-133 K.O. II, EP-1320 Medieval и EP-40 Riddim. Распознавание **не означает разрешение на запись**. |
| **Телефоны и планшеты** | Конвертация — по возможностям браузера; управление EP через My EP по MIDI не поддерживается. |
| **Проекты и Sequencer** | Только при подключённом и авторизованном EP. Просмотр сохранённого проекта не равен живой синхронизации и не разрешает изменения. |
| **Visuals** | Отдельный выбранный аудиовход; доступ к микрофону/USB Audio — по явному разрешению. Loudness показывает **RMS dBFS**, не LUFS. |

В Projects по умолчанию **AUTO: OFF**. Включённый пользователем `AUTO: ON` примерно раз в 20 секунд перечитывает **сохранённый** проект, когда это безопасно; это не Live и не чтение несохранённых шагов.

**Имена файлов:** экспорт SpeedUpperCut сохраняет числовые префиксы, например `056 Classic Kick_x2.wav`. При загрузке в My EP префикс `1`–`999` с пробелом/табуляцией или `_` может указывать слот и сниматься с имени **на устройстве**. Поведение конвертера и My EP различается; занятые слоты не следует перезаписывать без проверки.

Подробности: [поддержка браузеров](docs/testing/browser-platform-support.md), [матрица совместимости EP](docs/testing/ep-device-compatibility-matrix.md) и [правила аппаратной проверки](docs/TESTING.md).

## Что планируется

- **My EP REPITCH:** утверждённый, но **ещё не реализованный** переключатель, по умолчанию ON. Для нового локального импорта WAV с корректным `sound.pitch=-12` повторное ×2 пропускается; иначе выполняется подготовка ×2. Маркер `-12` — договорная метка, а не доказательство фактического ускорения. [Спецификация](docs/PRODUCT_RESEARCH.md#my-ep--repitch-toggle).
- **Saved Sequencer:** безопасный просмотр Step Sequencer и Piano Roll внутри My EP → Projects; **Live** — только после отдельного исследования MIDI/прошивки без выдуманного playhead. [Спецификация](docs/SEQUENCER.md).
- **Visuals:** дальнейшая доработка поведения полоски, тем и компоновок по уже утверждённым решениям. Требования и вопросы проверки — в [спецификации Visuals](docs/VISUALS.md); описание здесь не означает, что все будущие UX-детали уже реализованы.
- **Библиотека и обмен контентом:** исследование, а не запущенный сервис. Права на материалы, безопасность, приватность и финансирование ещё требуют решений. [Исследования](docs/PRODUCT_RESEARCH.md).

Утверждённые продуктовые решения, планы и реализованное поведение — разные вещи. Новая функция не считается доступной только потому, что описана в спецификации.

## Локальный запуск для разработчиков

Стек: статические **HTML/CSS/JavaScript**, Web Audio, Web MIDI/SysEx и WASM; для сборки и тестов используется **Node.js 22**. У опубликованного приложения нет отдельного серверного API и базы данных.

```bash
git clone https://github.com/Zatumanen/Ko-tool.git
cd Ko-tool
node scripts/check-codex-env.mjs
npm install --no-audit --no-fund
node tests/e2e/server.mjs
```

Откройте **http://127.0.0.1:4173/**. Перед Playwright E2E остановите вручную запущенный сервер: тестовый сервер использует фиксированный порт 4173.

### Проверки

```bash
npm test
npm run build:pages
npx playwright install chromium
npm run test:e2e
```

`npm test` выполняет Node-тесты, `test:e2e` проверяет сценарии в Chromium с **fake EP**, `build:pages` создаёт `dist/`. Автотесты **не подтверждают** безопасность записи на физический EP. Для аппаратной приёмки нужны точная модель/прошивка, явное разрешение, резервная копия, контролируемый сценарий и проверка данных после записи. См. [TESTING.md](docs/TESTING.md).

## Если что-то не работает

| Симптом | Что проверить |
| --- | --- |
| **My EP не видит EP** | USB, Chrome/Edge, HTTPS/localhost, разрешения Web MIDI/SysEx, модель и прошивка. Не открывайте одновременно два управляющих EP-приложения. |
| **Звук не декодируется** | Поддержку формата браузером; для диагностики попробуйте PCM WAV. |
| **Проект не обновился** | Нажмите **Refresh**: `AUTO: OFF` используется по умолчанию. |
| **Операция с сэмплом заблокирована** | Занятый слот, зависимости проекта, состояние устройства и разрешения. Не обходите защитные проверки. |
| **Visuals не получает сигнал** | Правильный аудиовход, разрешение браузера, START и наличие USB Audio или другого действительного источника. |

Для сообщения об ошибке укажите действия, браузер/ОС, модель EP и прошивку. **Не публикуйте** серийные номера, личные резервные копии, приватные SysEx-captures и секреты.
